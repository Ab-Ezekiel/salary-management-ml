# Salary Management ML System

## Setup Instructions

### 1. Clone repo
git clone https://github.com/YOUR_USERNAME/salary-management-ml.git
cd salary-management-ml

### 2. Create virtual environment (Windows)
python -m venv venv
venv\Scripts\activate

### 3. Install dependencies
pip install -r requirements.txt

### 4. Run dataset generation
python app/generate_data.py

### 5. Run model
python app/train_model.py
